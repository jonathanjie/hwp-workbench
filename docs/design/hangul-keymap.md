# 한글 단축키 → Mac 단축키 (확인 요청)

HWP Workbench는 Windows 한글을 쓰던 분이 Mac에서 같은 손 습관으로 작업하도록 만듭니다. 아래 표는 Windows 한글 단축키를 **기억에 의존해** 정리한 것입니다. 틀린 키는 고쳐 주시고, 자주 쓰는 키에 표시해 주세요.

*English: Windows Hangul shortcuts, from memory, for a daily Windows Hangul user to confirm. Mark wrong keys and the keys used daily.*

## Mac에서의 원칙

- Windows의 **Ctrl** = Mac의 **⌃ control** 또는 **⌘ command** (둘 다 동작).
- Windows의 **Alt** = Mac의 **⌥ option**.
- **F1–F12**: Mac은 기본적으로 `fn`을 함께 눌러야 합니다. 시스템 설정 → 키보드 → 키보드 단축키 → 기능 키에서 "F1, F2 등의 키를 표준 기능 키로 사용"을 켜면 Windows처럼 바로 동작합니다.
- **한/영 전환**: Mac은 Caps Lock(설정 시) 또는 한국어 키보드의 한/영 키. 앱이 이 키를 쓰지 않습니다.
- **한자 변환**: Mac 한국어 입력기의 ⌥ + Return (macOS 기능). 실제 입력 테스트로 확인 예정.
- macOS 시스템 키(⌃ Space 입력 소스, ⌘ Q, ⌘ W, ⌘ H, ⌘ Tab)는 덮어쓰지 않습니다.

## 저장 방식의 차이

Windows 한글의 Ctrl+S는 원본 파일에 덮어씁니다. HWP Workbench는 원본을 보호하기 위해 **항상 사본으로 저장**합니다(처음 저장할 때 이름을 묻고, 기본 이름은 `원본-edited.hwp`). 이 방식이 불편하면 알려 주세요.
